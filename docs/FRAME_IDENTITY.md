# 逐帧身份与追溯

InSituLink 1.1 为每帧保留物理身份、曝光区间、设备时间关系、参数来源和本次处理信息。一次曝光对应一条记录，不按参数值排序、合并帧或删除基线。

```mermaid
flowchart LR
 A[原始物理帧] --> B[曝光开始与结束]
 B --> C[各设备的时间映射]
 C --> D[参数支点与曝光统计]
 D --> E[逐帧记录与有效性]
```

## 身份的作用范围

`source_file + dataset + frame_index` 保留用户声明的原始定位，`frame_index` 从零开始且属于该文件/数据集。`sequence_index` 表示本次输入的采集顺序，不能替代文件内索引。HDF5 数据集别名、软硬链接和外链还要解析到实际对象；VDS 需保留逻辑位置与实际源帧映射，未映射位置不能作为有效物理帧。

为需要跨目录迁移的实验，可以在请求中持久保存标识：

```json
{
  "metadata": {
    "experiment_id": "experiment-2026-001",
    "acquisition_id": "acquisition-001",
    "detector_id": "detector-A"
  },
  "frames": {
    "assets": {"raw/master.h5": "asset-001"}
  }
}
```

上述只是配置片段，仍需完整的 frames 输入与 sources。标识由实验记录提供，或在导入时生成并保存为登记标识；生成 UUID 不代表已证实样品或扫描关系。迁移文件时保留资产标识，只更新路径；修改时钟偏移不应改变物理帧身份。

未提供这些标识时，仍可使用原有路径身份。每条记录明确身份范围及验证状态，避免把本次元数据行号当成跨实验永久身份。旧 UID 用作兼容选择标识；新增持久身份不能掩盖重复原始对象。文件内容完整性与元数据寻址校验分开记录，仅检查元数据不会声称已校验全部像素内容。

## 时间与参数来源

原有 `t_start_s`、`t_end_s`、`t_mid_s` 保持原时间表达，新增精确起点与局部相对时间用于计算：`time_origin_s`、`t_start_rel_s`、`t_end_rel_s`、`t_mid_rel_s`。绝对起点保存为十进制字符串，避免先转换为大数值浮点秒。高分辨率时间应以起点和相对量为准，不能对显示用的 UTC 浮点端点做差恢复短曝光。

逐帧记录同时保留时间字段、单位、原始值、输入行号以及实测或重建依据。每个 source 独立记录时间起点及其与探测器的关系。公开偏移始终遵守：

`外部记录时间 = 探测器时间 + Δt`

中点参数可反查原始支点及插值权重；曝光均值和极值关联所用日志区间、采样类型、最大允许间隔及覆盖率。连续量使用线性插值，阶梯量右连续保持。`coverage=1` 表示插值模型覆盖整个曝光，不代表实际采样捕获了所有更快的过程变化。

`.phase` 保留曝光中点的阶段含义，曝光内跨越阶段单独记录。阶段辅助筛选，不是样品物理状态的独立证据。时间关系未解决时保留候选及 null 正式偏移；参数无效时保留原因，不补零。

## 查看和交付

离线 `report.html` 提供逐帧搜索、有效性筛选、设备和时间筛选以及帧详情。无效原因包含帧级和必需通道级问题；可选通道失败不会自动否定其他完整参数。原始路径缺失、时间关系未确认、曝光不完整和未选择的帧分别显示。

`frames.csv` 适合表格处理；`frame_manifest.json` 保留身份清单；`frame_records.json` 保留逐帧追溯信息；`decisions.json` 保存设备时钟依据。`handoff.json` 引用这些产物，`status.json` 记录本次运行、输入摘要、版本和状态。

`completed` 表示对齐交付完成，不能替代原始数据和标定预检。报告同时呈现原始寻址验证与 `ready_for_integration`；DIDASFlow 的 `handoff` 消费者仍独立检查原始内容、HDF5 数据集与物理帧、来源哈希和标定配置。InSituLink 继续只发布文件，不启动消费者。

当前正式积分入口支持二维或三维 HDF5 数据集中的完整二维帧，并使用内置 Full 一维 Q 工作流。消费者按交接包中的选择顺序建立 VDS 引用，每个执行位置只对应一帧，不复制像素、不重排或合并原始帧。其 `integration_bindings.json` 保留“原 `frame_uid` 与物理位置—执行位置—实际谱文件”的对应关系；`frame_parameters.json` 保留全部原始帧记录、参数来源和有效性。选中帧即使参数无效，仍保留该帧及其原始空值、标志，不填零。

文件迁移需用明确的 `--path-map` 更新消费者访问位置，原始声明与 UID 仍保留。原始来源、标定或路径变化后，旧结果不能据同名文件直接复用；使用新输出目录或 `--existing-output versioned`。命令与恢复规则见 [DIDASFlow 交接使用说明](https://github.com/D-sudoasd/DIDASFlow/blob/main/didasflow/docs/insitulink-handoff.md)。
