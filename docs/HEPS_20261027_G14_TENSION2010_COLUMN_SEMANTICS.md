## 4. 为什么支持此解释，哪些还不能确认

已核实的数值事实：第七列在全表严格跟随第三列的 20 倍；应力与力/面积相符；第五列近似重复应力。它们应首先用于排除“多条独立应变通道”的误读。

作为百分数解释时，50–150 MPa 窗口的表观模量约 120.47 GPa，R² 约 0.9967；50–100 MPa 约 120.30 GPa，100–200 MPa 约 107.82 GPa。若坚持把第三列当毫米，该 50–150 MPa 窗口按 3 / 5 mm 标距给出约 3.61 / 6.02 GPa。模量尺度、总伸长尺度和列间关系共同支持百分数解释；不能仅靠材料典型模量反推一个“正确”应变。

软件摘要 `E=6.01 GPa` 乘 20 为 120.2 GPa，`Agt=162%` 除 20 为 8.1%，`Ag=143%` 除 20 为 7.15%。这些摘要与同一软件计算链相容，属于同源佐证，不能重复计作独立校准。`Rp=713 MPa` 等依赖应变定义的派生属性须重新评估，不能随单位解释自动沿用。

峰载至第 2789 行，若按 3 mm 工程应变解释，标距等效伸长增加 0.503283 mm，横梁同期增加 0.349 mm，力降低 524.81 N。加载链回缩、通道比例、标距和应变定义差异均可能影响此关系；目前缺少独立资料区分它们。不能把这段进一步拟合的柔度当作实测标定，也不能把 24.921035% 直接命名为标准断后伸长率。

原始最后一行是第 2790 行（274.354 s）：力 321.94801 N，约为峰力的 15%，第三列重复倒数第三行的值。疑似软件构造的试验终止点，原因尚未独立证明。原行保留并标记 `suspected_software_endpoint`；目前的诊断绘图、斜率拟合与对齐锚点选择排除此行。不得把它自动当成实测拉断时刻，也不要删除原记录。

## 5. 先前踩坑的原因与处理结论

| 先前做法 | 问题与本次处理 |
| --- | --- |
| 直接信任“变形mm”，按 `(第三列−基线)/Lo×100` 算应变 | 在当前百分数解释下重复换算；Lo=5 时再放大 20 倍，改用 3 mm 也不能解决语义错误 |
| 将巨大的第七列与第三列视为两个独立传感器结果 | 两列是精确比例关系，信息同源；先检验列间公式再判断通道 |
| 以“第三列行程远大于横梁”判断 G14 引伸计坏了 | 百分数原值与毫米量直接比较不成立；旧 `large_vs_crosshead` 不能继续充当 G14 传感器故障证据 |
| 为修复曲线预设 E=110 GPa，再自动扣机器柔度 | 未独立标定机器柔度；未解决单位之前，模型把尺度问题吸收到参数里 |
| 弹性段与塑性段分别拟合或强制拼接 | 值连续不保证斜率连续，会制造突变拐点；平滑拼接也不能补充缺失的标定证据 |
| 把衍射特征拐点当宏观屈服，或用曲线相关确认同步 | 晶格响应、宏观应变、设备时间属于不同证据；高相关不能替代共同触发或实测时钟 |
| 以脚本测试通过或曲线外观合理判断科学结论正确 | 数值可复现只验证计算；必须另行检查单位、传感器和时钟证据 |

旧输出保留以便追溯。六个 `TC4_*_20261104` 试算目录新增的 `SUPERSEDED_FOR_G14.md` 说明哪些 G14 应变解释已被替代；原表、模型参数、帧清单及 clock JSON 不回写。时间候选与源数据清点仍有参考价值，不能整包一概宣布失效或已确认。
