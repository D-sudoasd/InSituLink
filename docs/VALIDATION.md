# InSituLink 验证范围

本轮仅使用固定种子的合成数据和软件测试，没有真实线站数据。真值保存在演示目录的 `truth.json`，不被请求文件、偏移估计算法或阶段缓存读取。

- 输入检查涵盖 CSV/XLSX/JSON、时区和单位、NeXus 时间属性、填充与巨大虚拟长度、实际帧索引，以及元数据读取不访问像素。
- 数值检查涵盖线性及阶梯记录的解析曝光统计、缺口与越界、已知正负偏移、事件基线、多峰冲突、热响应歧义和往复阶段。
- 预分析检查涵盖伪 Voigt 拟合、不确定度、弱峰、重叠和消失峰、参考基线、q/d/2θ 转换，并实际调用 pyFAI 处理合成 HDF5 衍射环和掩膜。
- 运行检查涵盖 JSON CLI、独立设备、逐通道有效性、原始帧身份、离线报告、输入保护、失败交付撤销、缓存恢复、配置变化和损坏输出修复。
- 兼容检查使用原 `strainlink` CLI/API 与参考曲线映射 GUI 的既有测试。

| 演示 | 条件 | 预期 |
| --- | --- | --- |
| tensile | 独立时钟、共同加载事件、不同采样频率、不规则曝光 | 帧级偏移估计；保留基线 |
| thermal | 设备偏移和样品热响应延迟、升降温往复 | `needs_input`，不发布虚假已对齐结果 |
| multi | 多设备触发观测、通道缺值、长缺口、可选记录提前结束 | 独立偏移与逐通道有效性 |

在根目录运行 `py -3 -m unittest discover -s tests -v`。二维环测试需要安装 `preview` 额外依赖，跳过的测试不计作通过。

真实实验还需要核对时间字段含义、几何、波长、掩膜、积分方向及校正，独立确认共同事件及温度传感器和样品的响应关系。软件完成和有限的拟合误差不能替代这些实验依据。

## 初版验证记录（2026-10-25，提交 8668517）

Windows / Python 3.13.0：完整命令 `py -3 -m unittest discover -s tests -q` 通过 156 项测试，无跳过。wheel 构建、独立目录安装、从安装包运行拉伸演示均成功。

拉伸演示保留 100 帧，估计偏移为 7.332772 s，合成真值为 7.35 s，相差 0.017228 s。变温演示保留 123 帧，发布偏移为 null，候选约 -7.613103 s，正确保留设备偏移与样品响应延迟的歧义。多设备演示保留 120 帧，三个设备的锚点偏移分别为 6.25、-4.75、2.4 s；其中 103 帧具有全部必需参数的完整曝光覆盖。17 帧的局部无效记录仍保留在表和清单中。

输出目录保护、失败后交接就绪状态撤销、HDF5 越界帧禁止、缺失单帧时间的局部无效处理，均有回归用例。

该记录说明初版既有用例通过，不表示后续审查发现的九项问题不存在；PR #2 合并依据为修复后的回归、双版本测试和独立复核记录。
